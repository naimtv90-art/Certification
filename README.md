# Certificate Generator

Automated certificate generation tools for AI4BT Global Summit 2026.

## Features
- Dynamic text insertion and auto-scaling font sizing using PyMuPDF (`fitz`).
- Batch generation of certificates from Excel attendee lists.
- Generation of single certificates or per-person folders (PDF and PNG formats).

## Requirements
Install dependencies:
```bash
pip install -r requirements.txt
```

## Usage
Run the desired script:
```bash
python generate_certificates.py
```
